# Engineering notes

KaagazEdge ships as a local clerk, not as a cloud wrapper.

* Default inference is local.
* Target hardware is Snapdragon X and Snapdragon X2 HP PCs.
* Use Qualcomm AI Hub models on the Hexagon NPU when artifacts exist.
* If artifacts are missing, labelled stubs must remain labelled stubs.
* Python 3.11, type hints, UTF-8.
* No telemetry.
